# Contributing

This is a controlled personal portfolio. Changes must preserve evidence traceability, privacy, accessibility, and the static-first architecture.

1. Create a focused branch.
2. Update the private claim register before changing a factual claim.
3. Do not add source documents or personal contact data.
4. Run the verification commands in `AGENTS.md`.
5. Include screenshots for meaningful visual changes.
6. Describe privacy, content, accessibility, performance, and deployment effects in the pull request.

Publication requires Joseph's explicit approval even when automated checks pass.
